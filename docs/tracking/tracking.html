Strategy call tracking plan

What to send, when, and the JSON for each event. All events go to Segment. Every name starts with meeting_.

Include on every event

  1. Every event includes all UTMs, as separate properties. Read every utm_* parameter that is there, not a fixed list, and send each one as its own property. Never nest them, never hardcode values.
    first_touch_* is the first marketing touch ever.
    last_touch_* is read from the page where the visitor started the flow, the page where they clicked the CTA.
  2. Segment call type. The three page-view events are Segment page() calls (type page, category meeting, name = the event name). Send one page call per page load with that name, and do not also send a second generic page() on those pages. Everything else is a track call.
  3. Who and what: email as soon as it is known, booking_id once the booking exists, and the flow properties: booking_session_id, anonymous_id, flow_entry, flow_start, source_page, cta_id, variant_booking, variant_confirmation.

meeting_cta_clickedtrackBrowser

Fires when Click on any element with a data-cta attribute, on any site, blog or product page.

Extra properties cta_id string, e.g. "xyz_inline" · source_page string, e.g. "/page-xyz" · cta_text string, e.g. "Book a strategy call"

Implemented separately

The booking lifecycle and call events (reschedule, cancel, call held, no-show) and the email events (sent, clicked) are not part of this build. They are implemented separately, and only if tracking in Mixpanel is needed. Their definitions stay here so the names and data are agreed up front.

EventCallFires when
meeting_email_senttrackThe email platform accepts a send of any flow email.
meeting_email_clickedtrackTracked link click in a flow email.
meeting_booking_rescheduledtrackThe time of an existing booking is changed. Cal.com BOOKING_RESCHEDULED webhook.
meeting_booking_canceledtrackA booking is cancelled by the visitor or the host. Cal.com BOOKING_CANCELLED webhook.
meeting_call_heldtrackThe visitor joined the call.
meeting_call_no_showtrackThe visitor has not joined 15 minutes after the start.

Open points

  • last_touch is read from the page where the CTA was clicked. If that page's URL has no UTMs, should last_touch_* be empty, or fall back to the UTMs kept for the visit?
  • UTMs are dynamic: capture every utm_* parameter on the URL. Cal.com metadata allows 50 keys; 29 are used today and each extra utm_* adds two.
  • email is added to every event once known, which sends personal data to every Segment destination. The alternative is to rely on identify() and userId.
  • Add to Apple Calendar needs a link to an .ics file, which HubSpot emails cannot attach and which needs somewhere to be hosted.
